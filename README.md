# Code Task Runner

Build, test, and run tasks directly inside Matn with interactive terminal runner panel

## Details
- **Identifier**: `matn.ext.runner`
- **Version**: `1.0.0`
- **Category**: `tools`

## Installation
Inside Matn Editor, open the Extensions Marketplace (<kbd>Ctrl+Shift+X</kbd>), search for **Code Task Runner**, and click **[Install]**.

Alternatively, install directly from GitHub:
```
https://github.com/matn-extensions/ext-runner
```
